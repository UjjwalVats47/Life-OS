weekly task allocation system based on the following structured logic:

User Schedule Input: The user defines their weekly schedule by identifying fixed time blocks (e.g., school, meals, sleep) and flexible slots. This forms the foundation for all task allocations.

Goal Definition: After scheduling, the user sets a weekly goal (e.g., academic, fitness) that guides all task prioritization.

Task Categorization: Every task is categorized as Critical (high priority, high XP), Negotiable (flexible, moderate XP), and Small (lightweight, frequent tasks with low XP).

XP Assignment: Each task is assigned an XP value. Critical tasks yield the most XP, small tasks provide cumulative XP, and negotiable tasks sit in between.

Time Slot Allocation: Using the user’s schedule, the AI divides the week into slots. Fixed slots (like study or sleep) are locked. Flexible slots allow lighter tasks to be rearranged.

First-Come, First-Serve Logic: The first tasks chosen lock their slots. If skipped, they are rescheduled. After 3 or 4 cycles of postponement, the task escalates to a hard deadline slot.

Sunday Deadline Catch-Up: If tasks remain incomplete, the AI prioritizes them toward Sunday. Even if other tasks are planned, leftover tasks are fixed that day, ensuring completion before the next week.

Streak and Goal Review: After the week, the AI checks if all tasks (including catch-ups) were done. If yes, it records a successful week and builds a streak if done multiple weeks in a row.
